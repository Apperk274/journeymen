# Journeymen

A Minecraft 1.21.1 mod for NeoForge and Fabric. Hire a foreman, hand him a schematic, materials and tools, and his crew of builders build it block by block, the way a player would.

Status: phase 4 (survival UI) implemented, waiting for in-game testing; phase 6 (foremen) is designed but not built yet. In that design you hire a foreman from a craftable Recruiter's Stall, he hires builders for his crew, and you give him a schematic by placing a ghost preview in the world. He keeps the job, the supply and dump chests and the plan, shows progress in a boss bar and keeps you informed, while his builders clear the site and build it by hand. Everything can also be done with `/journeymen` commands. It works with TerraFirmaCraft modpacks: TFC soils, farmland, paths, buckets, storage and emeralds are handled, and `:neoforge:runTfcServer` / `:neoforge:runTfcClient` run it with a TFC mod set (see `CLAUDE.md`). See `CLAUDE.md` for the design and roadmap.

## Requirements

- [mise](https://mise.jdx.dev/), which provides Java 21 from `mise.toml`
- Everything else (Gradle, Minecraft, the loaders) is downloaded by the Gradle wrapper

```sh
mise trust
mise install
```

## Building and running

Run Gradle through mise so it picks up Java 21:

```sh
mise exec -- ./gradlew build                   # jars for both loaders
mise exec -- ./gradlew :neoforge:runClient     # dev client on NeoForge
mise exec -- ./gradlew :fabric:runClient       # dev client on Fabric
mise exec -- ./gradlew :neoforge:runData       # data generation (NeoForge)
```

Built jars land in `neoforge/build/libs/` and `fabric/build/libs/`. Use the one without `-sources` in the name.

The first build downloads and decompiles Minecraft for each loader and takes several minutes. Later builds take seconds.

## Layout

| Module | Contents |
|---|---|
| `common/` | Shared code. Compiled against vanilla Minecraft only, so it cannot import NeoForge or Fabric classes. Most of the mod lives here. |
| `neoforge/` | NeoForge entry point (`JourneymenNeoForge`) and NeoForge-specific wiring. |
| `fabric/` | Fabric entry point (`JourneymenFabric`) and Fabric-specific wiring. |
| `buildSrc/` | Gradle conventions shared by the modules. |

Common code reaches loader features through interfaces in `common/.../platform/services`. Each loader provides an implementation, registered in `META-INF/services/` in that loader's resources.

Based on [MultiLoader-Template](https://github.com/jaredlll08/MultiLoader-Template) (1.21.1 branch).

## Editor

Open the folder in VS Code and install the recommended extensions (Java Extension Pack, Gradle for Java). `.vscode/settings.json` points VS Code at the mise-installed JDK. It's machine-specific and not committed, so on another machine set `java.import.gradle.java.home` to your own JDK 21 path.

IntelliJ IDEA with the Minecraft Development plugin also works and generates run configurations automatically.

## Example schematics

`examples/schematics/` has schematics that show off what a builder can do. Copy them into the `schematics/` folder of your game directory (the dev run folders already have them). The mod reads WorldEdit/Sponge `.schem`, Litematica `.litematic`, vanilla structure `.nbt` and old MCEdit/WorldEdit `.schematic` files from that folder and its subfolders.

- `wheat_farm.nbt`: tilled farmland around a water source with wheat, carrots, potatoes and beetroot (planted young, like a player would), a fence with a gate and torches.
- `cottage.schem`: a small house saved by WorldEdit with a paste offset, so its origin is the front door.
- `decor_corner.nbt`: a lectern with a book, a jukebox with a disc, a chiseled bookshelf, a decorated pot, a patterned banner and a glowing sign.
- `redstone_demo.nbt`: a lever, redstone dust, a repeater, a lamp and a piston.
- `clear_area.schem`: 9×8×9 of air, to watch a builder clear terrain or trees.
- `garden_shed.litematic`: a Litematica schematic with two regions, a shed and a garden that extends the other way from the origin.
- `old_hut.schematic`: an old MCEdit/WorldEdit schematic from Minecraft 1.12, converted on load (blue bed, potted poppy, sign text).
- `uploaded/Steve/watchtower.nbt`: a schematic in a subfolder, where Create keeps uploaded schematics. Name it with its path in quotes: `"uploaded/Steve/watchtower.nbt"`.
- `test_*`: edge cases (an old Minecraft version with a block from a missing mod, a broken file, an unplaceable nether portal, legacy block ids this game doesn't know).

They are generated by `python examples/make_schematics.py`.
